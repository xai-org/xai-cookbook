    Refunds that wait for a person

    The agent reads a customer's email, looks up the order and the refund policy, and proposes a refund. Then it stops before any money moves and saves where it stopped. When someone approves, it picks up the same run, issues the refund once, and writes back to the customer.

    1. Send a request. Pick a sample, or write your own.
    2. Restart the server while the refund waits. Stop npm run web and start it again.
    3. Approve it. The run continues from the response it stored before the restart.
