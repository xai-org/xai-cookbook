# Hyper-Personalized Marketing

Use Grok to create marketing material for individual customers, complete with custom copy and images.

## What you'll learn

- Generate realistic customer profiles as structured output
- Write marketing copy tailored to each customer
- Generate a matching image for each piece with `grok-imagine-image-2.0`

## Run it

Open [`python/guide.ipynb`](python/guide.ipynb). If you haven't set up the repo yet, follow [Run the notebooks](../../README.md#run-the-notebooks) in the main README. Generated images are saved to [`python/generated_images/`](python/generated_images/).
