Keep the start of the prompt the same

Every turn of a chat sends the whole chat again, and the part that matches the start of the last prompt is read from the cache at a quarter of the price. These three chats send the same 30 messages and all tell Grok the time. The first two put it in different places, and the third also compacts as it goes.

Time in the message

The time starts the latest message, so each prompt starts with everything the last one sent.

Time on top

The time starts the system prompt and changes on every turn, so no two prompts start the same way.

With compaction

Like the first, but every 1,500 tokens of turns are swapped for one summary item, which the next turn reads as new.

  • Read from the cache, $0.50 per million tokens
  • New, $2.00 per million tokens
  • A compaction's summary, new on the turn after it

It takes 2 to 4 minutes and costs about 60 cents at list price.
