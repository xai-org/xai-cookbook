Grok transcribes the speech with the timing of every word, translates each line to fit the time the original took, and records it in a voice for each speaker. Lines that run long are shortened and recorded again, and the dub is mixed over the original background.

  2. TranslateGrok translates the lines, with a length budget for each from the time the original took.
  3. Record and fitEach line is recorded and measured. If it runs long, Grok shortens it and it's recorded again.
  4. Mixffmpeg turns the original sound down and lays each line where the original was spoken.
