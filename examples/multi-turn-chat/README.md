# Building a Unified Chat Experience

Build up a chat app one feature at a time, starting with a streaming conversation and ending with a chat that can call tools and read images.

## What you'll learn

- Keep a multi-turn conversation going and stream Grok's replies
- Add function calling to the chat loop
- Read receipt images and get structured output back

## Run it

Open [`python/guide.ipynb`](python/guide.ipynb). If you haven't set up the repo yet, follow [Run the notebooks](../../README.md#run-the-notebooks) in the main README.

The chat cells are interactive: type a message and press Enter to send it, and type `exit` to stop.
