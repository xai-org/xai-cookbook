    Ask your documents

    Grok answers from the passages a search finds in your collection and cites each one, so you can check it. A metadata filter decides which documents count. When the documents don't say, it tells you instead of guessing.

    Upload the documents first

    The page answers from a collection that npm run ingest creates. Creating it takes a management key as well as your API key.

    1. In the SpaceXAI Console, open Settings, then Management Keys, and create a key that can create collections and add documents to them.
    2. Add it to .env at the root of the repo as XAI_MANAGEMENT_API_KEY.
    3. Run npm run ingest, then reload this page.
