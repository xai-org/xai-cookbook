# Object Detection

Combine Grok's language understanding with its image understanding to find objects in photos just by describing them.

## What you'll learn

- Count objects in a busy scene
- Get bounding boxes back as structured output and draw them on the image
- Find niche objects, apply your own criteria, and read text in several languages

## Run it

Open [`python/guide.ipynb`](python/guide.ipynb). If you haven't set up the repo yet, follow [Run the notebooks](../../README.md#run-the-notebooks) in the main README. The sample photos are in [`python/images/`](python/images/).
