Receipts to Spreadsheet

grok-4.7 with the Files API, or grok-4.3 with the Batch API View code

Receipts in, a spreadsheet that adds up out

Drop receipt photos and PDF invoices anywhere on the page. Grok reads each one twice, checks that the line items, tax, and tip add up to the total, and marks every cell where the two reads disagree.

The eight samples take under a minute and cost about 9 cents.
